使用`Math`库函数之前，需要先引入`Math.h`头文件：

```c
#include <math.h>
```

## 平方根

返回值为输入整型数值的平方根

```c
printf("result = %f\n", sqrt(16));

// 运行结果
// result = 4.000000
```

> 返回值为浮点型
{: .prompt-warning}

## 四舍五入

`ceil()` 函数将一个数字向上舍入到最接近的整数，而 `floor()` 方法将一个数字向下舍入到最接近的整数，并返回结果：

```c
printf("%f\n", ceil(1.4));
printf("%f\n", floor(1.4));

// 运行结果
// 2.000000
// 1.000000
```

## Power

`pow()` 函数返回 `x` 的 `y` 次方 (x<sup>y</sup>)：

```c
printf("%f\n", pow(4, 3));

// 运行结果
// 64.000000
```

## 其他数学函数

下表列出了其他流行的数学函数（来自 `<math.h>` 库）：

| 函数 | 描述 Description |
| -------- | --------------------------------------- |
| abs(x)   | 返回 x 的绝对值 |
| acos(x)  | 返回 x 的反余弦值 |
| asin(x)  | 返回 x 的反正弦值 |
| atan(x)  | 返回 x 的反正切 |
| cbrt(x)  | 返回 x 的立方根 |
| cos(x)   | 返回 x 的余弦 |
| exp(x)   | 返回 Ex 的值 |
| sin(x)   | 返回 x 的正弦值（x 以弧度为单位） |
| tan(x)   | 返回角度的正切 |
