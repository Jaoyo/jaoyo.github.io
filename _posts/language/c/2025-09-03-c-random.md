C 库函数 `int rand(void)` 返回一个范围在 `0` 到 `RAND_MAX` 之间的伪随机数。

`RAND_MAX` 是一个常量，它的默认值在不同的实现中会有所不同，但是值至少是 32767。

## 声明

```c
#include <stdlib.h>

int rand(void);
```

## 返回值

返回一个范围在` 到 `RAND_MAX` 之间的整数值

## 使用示例

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
 
int main()
{
   int i, n;
   time_t t;
   
   n = 5;
   
   /* 初始化随机数发生器 */
   srand((unsigned) time(&t));
 
   /* 输出 0 到 49 之间的 5 个随机数 */
   for( i = 0 ; i < n ; i++ ) {
      printf("%d\n", rand() % 50);
   }
   
  return(0);
}
```
