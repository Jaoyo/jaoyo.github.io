## 显示行号

* 命令

在vim的命令模式下输入`: set number`或`:set nu`

如果取消，输入`:set nonu`

* 配置文件修改

```vim
set number
``` 
{: file="~/.vimrc"}

## Tab宽度

```vim
set expandtab           // 空格代替Tab
set tabstop=4           // 设置制表符宽度为 4
set softtabstop=4       // 设置软制表符宽度为 4
set shiftwidth=4        // 设置自动缩进时的空格为 4
```
{: file="~/.vimrc"}

## 设置自动缩进方式

```vim
set autoindent          // 通用
set smartindent
set cindent             // 针对C/C++
```
{: file="~/.vimrc"}

## 语法高亮

```vim
syntax on
```
{: file="~/.vimrc"}

## 高亮当前行

```vim
set cursorline
```
{: file="~/.vimrc"}

## 搜索高亮

```vim 
set hlsearch        // 高亮所有匹配的搜索结果
set incsearch       // 增量搜索，当你输入搜索内容时，Vim 会实时高亮匹配项
```
{: file="~/.vimrc"}
